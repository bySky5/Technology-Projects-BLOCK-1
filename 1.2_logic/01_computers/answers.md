Component
CPU: Central Procesor Unit (CPU), it is the main component for a computer to function. It is in charge of processing
programmes  by any instructions given, such as arithmetic, logic, controlling and input/output.
RAM: Random Access Memory (RAM), is a type of computer memory that can be read and changed in any order.
Storage: is a hard drive, such as SSD or HDD for storing data, files, OS.
Motherboard: is a board that connects together each component of a computer.
Power supply: Delivers a power to the computer.
Cooling: keeps a computer components from overheating.
